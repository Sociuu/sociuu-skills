# Sociuu Skills

Minimal, provider-neutral action skills for Sociuu engineering work.

Install them with the open skills CLI:

```bash
npx skills add Sociuu/sociuu-skills --skill '*' -a codex -a claude-code
```

The catalog composes existing owners rather than replacing them: Compound
Engineering owns code work and browser dogfooding; Dock owns local runtime
lifecycle; Apex Scaffolding owns synthetic data; the forge and CI own delivery
evidence; humans own merge and deployment.

## Symphony baseline

Sociuu Symphony is the always-on operating policy, not an installable skill.
Its canonical source is [instructions/SYMPHONY_BASELINE.md](instructions/SYMPHONY_BASELINE.md).
Add or reference that baseline from each repository's always-loaded instruction
surface for Codex, ChatGPT, and Claude. It gives agents foreground autonomy
inside confirmed scope, regardless of which action skill they later invoke.
