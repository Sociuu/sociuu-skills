# Skill routing

Conditional automatic means inside authorized work when the trigger occurs.
Explicit includes a specific natural-language request or accepted recommendation.
These are policy rules; host-specific discovery controls require validation.

| Trigger | Route | Selection |
| --- | --- | --- |
| Factual question/trivial edit | Direct tools/response | No workflow by default |
| Ambiguous report | sociuu-investigate | Conditional; read-only unless fix authorized |
| Implementation start/evidence milestone | sociuu-task | Conditional |
| First write/expanded write set | sociuu-task-isolation | Conditional before writes |
| Bounded understood implementation | Host coding tools | Default |
| Sustained plan implementation | ce-work implementation-only | Conditional |
| Difficult diagnosis | ce-debug | Conditional; not also diagnosing-bugs |
| Select/reconcile acceptance evidence | sociuu-verify | Conditional before/after implementation |
| Integrated runtime/data needed | dock / Apex Scaffolding | Conditional |
| Numeric meaning changes | sociuu-before-and-after | Conditional assessment; access authority applies |
| Economical uncovered human checks | sociuu-qa-guide | Conditional |
| Second local review | sociuu-coderabbit | Conditional after repository review |
| Existing review feedback | sociuu-resolve-git | Conditional within authorized scope |
| Shipping/post-staging follow-through | sociuu-ship / sociuu-finalize | Specific request or authorized continuation |
| Exploratory QA | sociuu-aq → ce-dogfood | Explicit |
| Substantial plan/scoping | ce-plan / ce-brainstorm | Explicit |
| Deep review/document review/panel | ce-code-review / ce-doc-review / ce-pov | Explicit or accepted risk-based recommendation |
| Alternatives/prototypes | ce-ideate / ce-bakeoff / ce-prototype | Explicit |
| Suitable behavioral test seam | tdd | Conditional; explicit test-first always applies |
| Domain/interface decisions | domain-modeling / codebase-design | Conditional |
| Instruction authoring | writing-for-agents | Conditional |
| Verified non-obvious reusable lesson | ce-compound | Conditional; not personal-memory authority |
| Context transfer | ce-handoff | Specific transfer or needed checkpoint |
| Prompt rewrite | prompt-enhancer-preflight | Explicit; never execute rewritten prompt |
| Interview | grilling / grill-ai-design-builder | Explicit |
| Full orchestration | lfg / Maestro / Matt implement or wayfinder | Explicit; Sociuu gates prevail |
| Protected hotfix | sociuu-ship-hotfix | Explicit Production scope only |

Prefer one installation source and one default route per activity. CE and Matt
are optional providers, not competing mandatory lifecycles. Specialized tools
retain required prerequisite skills. Do not uninstall unrelated capabilities
merely to shrink a coding catalog. Do not edit managed plugin caches.

Verify explicit-only metadata on each host. Where selective discovery is unavailable,
use supported profiles or selected installations, or report policy-only enforcement.
No host may claim capabilities it lacks.
